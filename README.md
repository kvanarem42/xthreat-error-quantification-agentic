# xthreat-error-quantification
Research into the error quantification of an expected threat (xThreat) model

# About the project
This project studies the error in estimating the Expected Threat (xThreat/xT) in football. This framework, introced by ... and popularized by ..., estimates the probability of scoring when having ball possession in a certain place. The goal of this research was to study the errors of this model when estimating these probabilities based on data. Additionally, this can be translated to rules of thumb for practitioners to use the Expected Threat model.
